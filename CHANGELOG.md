# Changelog

## 1.2.0 — 2026-09-15

First public open-source release.

- Native macOS menu bar control panel for FreeBuds SE 4 ANC.
- Separate battery readings, ANC/awareness modes, EQ, low-latency preference and gesture configuration.
- Device-verified setting writes with readback, visible unknown states and explicit model checking.
- Light/dark/system appearance, native macOS 26 glass navigation and original source-drawn artwork.
- GPL-3.0-only licensing and OpenFreebuds attribution.
- English/Turkish documentation, protocol checks, two-architecture CI and checksummed release archives.

The private 1.0/1.1 development builds preceded this public release. They were not GitHub releases.
