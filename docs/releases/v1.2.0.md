The first public release of **FreeBuds Kontrol**, a native Mac menu bar app for **HUAWEI FreeBuds SE 4 ANC**.

### Included

- Left/right/case battery readings and charging indicators.
- Noise cancellation, awareness, ANC intensity, EQ and low-latency preference.
- Per-ear double/triple/hold gestures, noise cycling and call gestures.
- Light/dark/system appearance with native macOS materials.
- Original illustrations and GPL-3.0-only source code.

### Download

- **Apple Silicon:** `FreeBuds-Kontrol-1.2.0-arm64.zip`
- **Intel:** `FreeBuds-Kontrol-1.2.0-x86_64.zip`
- **Integrity:** `SHA256SUMS.txt`

Requires **macOS 14+**. The interface is **Turkish**; the README is available in English and Turkish. Builds are ad hoc signed, **not Apple-notarized**. See the [installation guide](https://github.com/hikmetozcann/freebuds-kontrol#installation) for first launch.

Hardware validation covers model **BTFT0026**, firmware **1.9.0.199**, on an Apple Silicon Mac with macOS 26.3. Other combinations remain unverified. **This release does not add multipoint, automatic iPhone/Mac switching or firmware flashing.**

Both binaries are compiled and checked on their respective GitHub-hosted Mac architectures from the same source commit. Corresponding GPL source is available in the tag archives below; protocol attribution is in `NOTICE.md`.
